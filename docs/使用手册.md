# 使用手册

> 给日常操作用。技术细节看 `README.md`。

---

## 一、启动与登录

1. 双击 `start.bat`，浏览器会自动打开 `http://127.0.0.1:9527`
2. 左侧点「账号」
3. 填个名字（比如"主号"）→ **新增账号**
4. 点该行的 **打开登录** → 会弹出一个独立的 Chrome 窗口
5. 在这个窗口里扫码登录抖音（**这个窗口就是该账号的专属环境**，之后所有任务都在里面跑）
6. 回来点 **检查登录**，显示「已登录」即可

> 每个账号一个独立 Chrome 窗口、独立 Cookie、独立指纹。窗口关掉不影响，下次任务会自动拉起。

多个账号就重复 3–6 步。账号多了以后任务会自动轮换使用（除非你指定账号）。

---

## 二、采集

都在「采集」页。选好账号 → 填参数 → 点按钮 → 去「日志」看进度。

| 想做什么 | 填什么 | 得到什么 |
|---|---|---|
| 搜关键词视频 | 关键词 + 数量 | 文案、作者、点赞/评论/收藏/分享数、发布时间、链接 |
| 搜关键词用户 | 关键词 + 数量 | 昵称、抖音号、粉丝、关注、获赞、简介、sec_uid |
| 搜直播间 | 关键词 | 房间号、标题、主播、在线人数 |
| 抓某人作品 | 该用户的 sec_uid | 他主页的作品列表 |
| 抓某人资料 | 该用户的 sec_uid | 昵称、简介、粉丝数等 |
| 抓粉丝/关注 | sec_uid + 选「粉丝」或「关注」 | 对方列表（昵称、抖音号、粉丝数） |
| 抓评论 | 作品 ID（可多个，逗号分隔） | 评论内容、用户、点赞、时间 |
| 拉私信会话 | 不用填 | 会话列表：对方昵称、最后一条、未读数 |
| 批量下载 | 分享链接/作品链接，每行一个 | `data/downloads/日期/` 下的 mp4 / jpg / mp3 |

**sec_uid 怎么拿**：打开对方主页，地址栏是 `douyin.com/user/MS4wLjAB...`，`MS4wLjAB...` 那串就是。

**作品 ID 怎么拿**：打开视频，地址栏 `douyin.com/video/7xxxxxxxxxxx`，数字那串就是。

## 三、互动

「互动」页。**建议先从小批量试**。

| 动作 | 填什么 |
|---|---|
| 点赞 / 收藏 | 作品 ID，每行一个 |
| 关注 | 对方 sec_uid，每行一个 |
| 评论 | 作品 ID + 话术（多条用 `|` 分隔，随机取一条） |
| 私信 | 对方 sec_uid + 话术 |

执行前会先读当前状态：已点赞的跳过、已关注的跳过，不会重复点。

**降低风险**：设置页把「最小延时」调到 4000ms 以上，「并发」保持 1。批量越大越容易触发风控。

---

## 四、直播弹幕

「直播」页：

1. 填直播间号（地址栏 `live.douyin.com/` 后面那串数字）
2. 点 **开始监听**
3. 左边实时滚动弹幕/进场/礼物/点赞，右边是已入库记录
4. 下拉框可以只看弹幕或只看礼物

监听期间不要关那个 Chrome 窗口。点「停止」结束。

> 弹幕是从页面自己的连接里旁路读出来的，不需要额外登录或签名。

---

## 五、数据与导出

「数据」页：

- 上方选数据源（作品/用户/评论/直播/会话）
- 关键词框是**全文检索**，支持任意中文子串（搜"香锅"能命中"麻辣香锅"）
- 可以按任务 ID、日期范围过滤
- **导出 Excel** / **导出 CSV** 会按当前筛选条件导出

数据存在 `data/douyin.db`（SQLite 文件），想备份直接复制这个文件（先停服务）。

## 五·补、按地域找本地客户（实体店必看）

做本地生意（贴膜、餐饮、家装）时，评论区的人来自全国各地，泛关键词捞到的常常是外地人。

实测数据：用「隐形车衣」这类泛词采 595 条评论、筛出 116 个意向用户，抽 30 个查 IP 属地——

```
广东 9   浙江 3   山东 3   江苏 3   安徽 2   江西 2
北京 1   黑龙江 1  内蒙古 1  贵州 1   湖南 1   辽宁 1
```

**本地只占约 10%。**

### 正确做法（四步）

**1. 用本地关键词搜内容**

```
杭州贴膜、杭州隐形车衣、杭州改色膜
```

本地博主的内容下，本地人比例明显更高。

**2. 采爆款评论**

按点赞排序挑前 5 条，采评论（单条爆款能采 80–150 条）。

**3. 采用户资料看 IP 属地**

评论数据里只有 `region: "CN"`，**没有省市**。要判断地域必须采用户主页：

「采集」→ 用户主页 → 填 sec_uid → 采作品/只抓资料

采完后「数据」→ 用户，IP 属地会存在用户记录里。

**4. 筛出来私信**

### 两个限制要知道

- **抖音 IP 属地只到省**（"IP属地：浙江"），拿不到市。话术里直接问"您在哪个城市"更可靠。
- **简介里常带城市**，可以一并筛：简介含"杭州"的，比 IP 属地在浙江的更可能就在杭州。

### 效率参考

| 环节 | 耗时 |
|---|---|
| 搜关键词（20 条） | 约 40 秒 |
| 采 5 条爆款评论（约 350 条） | 约 4 分钟 |
| 采 30 个用户资料 | 约 8 分钟 |
| 发 10 条私信 | 约 4 分钟 |

一轮完整流程约 20 分钟，能产出 3–10 个本地意向客户。

## 六、定时任务

「定时」页：

1. 填名称
2. 选任务类型（搜视频/搜用户/作品/评论/粉丝/关注/会话/直播监听）
3. 填参数 JSON，例如 `{"keyword":"美食","limit":50}`
4. 填间隔分钟数
5. 账号 ID 可留空（用在线账号轮换），也可填 `1,2` 指定
6. 点 **创建**

到点自动入队。列表里可以「立即跑」「停用」「删除」。

---

## 七、代理与多账号

- 「代理」页：粘贴代理地址（`http://user:pass@host:port` 或 `host:port`）→ 添加 → 点「检测」看出口 IP 和延迟
- 账号挂代理：「账号」页 → 该行 **代理** 按钮 → 填地址（留空清除）
- 换账号 = 换环境；同一个账号的指纹每次启动保持一致

## 八、出问题怎么办

| 界面提示 | 原因 | 处理 |
|---|---|---|
| `账号 #N 未登录` | 没扫码或登录态过期 | 账号页 → 打开登录 → 重新扫码 |
| `未找到点赞按钮（选择器需更新）` | 抖音改版 | 改 `src/douyin.js` 顶部 `SEL`，或告诉我 |
| `未取到可用标签页` | Chrome 启动中 | 等几秒重试；持续出现就关掉该账号浏览器重新打开 |
| `验证码` / 频繁失败 | 触发风控 | 调大延时、减少批量、换账号或换代理 |
| 采集到 0 条 | 未登录 / 关键词太冷门 | 先在浏览器里手动搜一次确认能搜出来 |
| 端口 9527 被占用 | 上一次没关干净 | 会自动顺延到 9528，看控制台提示的地址 |
| 私信发不出去 | 对方设置不接受 / 账号权重低 | 属正常，日志会记原因 |

---

## 九、日常建议

- 每天开一次「检查登录」，登录态过期会静默失败
- 采集类任务风险低，互动类（点赞/评论/私信/关注）风险高，小步慢跑
- 数据定期导出留存，`.db` 文件也会越来越大
- 换账号/换 IP 比堆量更有效
