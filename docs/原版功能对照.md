## 一、原版功能全景（从视频逐帧提取）

### 1. 分发形态

视频开头展示的安装包结构：

```
CFLib
data
download
【必看】软件安装教程
1.数据教程  2.下载update.exe
update
抖音综合工具.exe
杭州AI视频工具.exe
杭州综合工具.exe
视频批量处理.exe
```

- 四个独立 exe（综合工具 / AI视频工具 / 综合工具 / 视频批量处理）
- `update` 目录用于自动更新
- 旁白强调"update 一定要保持要删除"（更新后清理）

### 2. 顶部菜单（五个采集模块 + 两个工具项）

```
【引流】自动化操作区 │ 【采集】搜索视频 │ 【采集】视频评论 │ 【采集】群成员 │ 【采集】视频/用户 │ 更新 │ 用户二维码
```

### 3. 各模块功能

#### ① 【采集】搜索视频

| 项 | 内容 |
|---|---|
| 输入 | 搜索关键词（支持 `关键词\|关键词` 竖杠分隔多个） |
| 左侧 | 内嵌浏览器实时显示抖音搜索页 |
| 右侧 | 一键视频采集 / 链接框 / 开始采集 / 停止采集 |
| 表格列 | 编号、标题、链接、视频链接、发布时间、UID、抖音号、昵称、简介、地区、粉丝、关注 |
| 输出 | 右键全选 → 复制视频链接；导出 Excel 全部导出 |

旁白："所有的视频相关的一个采集出来"、"这个工具的话呢有个不同点，是先把……"、"这时候就把点赞啊"

#### ② 【采集】视频评论

| 项 | 内容 |
|---|---|
| 输入 | 粘贴视频链接（从搜索视频模块 copy 过来） |
| 条件筛选 | 实时筛选、地区含、性别、评论含、降重、评不含、日期起、去除重复发言用户 |
| 表格列 | 编号、链接、时间、昵称、评论内容、UID、抖音号、性别、地区、简介、粉丝、关注 |
| 操作 | 一键筛选、全部删除、导出Excel、导入Excel、备份、恢复备份 |
| 联动 | 勾选评论 → "全部勾选到私信区" |

旁白："我们就可以到采集视频的评论里面"、"评论区是包含副业"、"我怎么跟他去做建联"、"全部勾选到私信区"

**关键**：评论表直接带评论者的性别/地区/简介/粉丝/关注——原版在采集时就把用户资料带回来了。

#### ③ 【引流】自动化操作区（私信）

| 项 | 内容 |
|---|---|
| 输入 | 私信内容（话术） |
| 参数 | 时间间隔（旁白说"两三分钟左右是可以的"即两三分钟一条） |
| 附带 | 点赞、收藏等其他动作可选 |
| 来源 | 从评论模块"全部勾选到私信区"传过来 |

旁白："那我可以对他进行私信内容"、"或者是啊点赞收藏啊"、"这里也会有其他的一些功能的选择"

#### ④ 直播间发言区

| 项 | 内容 |
|---|---|
| 输入 | 批量添加直播间链接 |
| 输出 | 弹幕/发言"全部在这里体现" |

旁白："第三个是关于直播间的发言区"、"把对应的直播间链接全部添加进来"

#### ⑤ 博主监控

| 项 | 内容 |
|---|---|
| 输入 | 博主的 UID / 首页链接 |
| 监控 | 什么时候发笔记、发什么内容 |

旁白："是给你的想要去监听的一个呢博主"、"比如说他什么时候发笔记"、"UID啊它的一个首页的一个链接"、"发什么内容啊"

#### ⑥ 评论监听

| 项 | 内容 |
|---|---|
| 场景 | 指定视频/账号，有人评论时触发 |

旁白："大家最常用的一个呢评论的一个监听"、"有人去评论的时候"

#### ⑦ 内容生成

| 项 | 内容 |
|---|---|
| 输入 | 把想要的文案全部粘贴进来 |
| 类型 | 爆款文案、话术、论文指导类型等 |
| 作用 | 生成/改写内容 |

旁白："就是我们在做制作的时候"、"把我们想要的文案全部粘贴进来"、"比如说量火的"、"就是对于话术的"、"比如说论文指导类型的"

#### ⑧ 多开与代理

| 项 | 内容 |
|---|---|
| 多开 | 同时启动多个实例（旁白演示打开第二个 exe） |
| 代理 | 支持 SOCKS5 格式 |

旁白："比如说说我们想要去多开"、"在同时运行过程当中呢"、"SOCKS5 这个格式"

## 三、优先补齐清单

按对贴膜业务的实用度排序：

| 优先级 | 功能 | 理由 | 工作量 |
|---|---|---|---|
| P0 | 博主监控（新作品通知） | 盯同行发什么，直接决定选题 | 中 |
| P0 | 评论实时监听 | 竞品爆款下有人问价，第一时间捞 | 中 |
| P1 | 私信附带点赞/收藏 | 提高通过率，降低被判营销 | 小 |
| P1 | SOCKS5 代理验证 | 多账号防关联 | 小 |
| P2 | 内容生成（文案/话术） | 有现成话术库，缺生成 | 大 |
| P2 | 备份到文件 | 当前只存浏览器 | 小 |
