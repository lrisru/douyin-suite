## 三、本轮补齐的四个功能

### 1. 监控（`src/watch.js`）

- 表：`watches(type, target, note, interval_sec, last_cursor, hits)`
- 类型：`user_new_works`（博主新作品）、`video_new_comments`（视频新评论）
- 策略：首次检查只记录基线，之后比对 cursor，发现增量即入库 + 通知
- 触发：每 20 秒扫一次到期项，单次最多 3 项，避免风控
- 接口：`GET/POST /api/watches`、`POST /api/watches/:id/check`、`POST /api/watches/:id/toggle`、`DELETE /api/watches/:id`
- 界面：点「【引流】自动化操作区」进入监控面板

### 2. 文件备份（`/api/backup`、`/api/restore`、`/api/backups`）

- 备份：全量导出 items/users/comments/lives/conversations 到 `data/backups/backup_<时间戳>.json`
- 恢复：读文件回灌（upsert）
- 实测：595 评论 + 411 作品 + 219 用户 → 42 MB

### 3. 内容生成（`src/generate.js`）

- 三类模板：私信话术（5 条）、评论话术（4 条）、标题（5 条）
- 变量：车型、预算、城市、品类、质保
- 意图解析 `parseIntent(text)`：从评论里反推车型/预算/城市/品类
- 实测：`理想L6白色，预算4000左右，杭州` → `{car:"理想L6", budget:"4000", city:"杭州"}`

### 4. SOCKS5 代理检测（`src/socks5.js`）

- 零依赖手写握手：`05 01 00` → `05 00` → `CONNECT` → `05 00`
- 支持无认证与用户名密码认证
- 错误码映射（代理故障/主机不可达/连接被拒等）

## 五、与原版的架构差异（功能等价，实现不同）

| 方面 | 原版 | 本项目 |
|---|---|---|
| 内嵌浏览器 | CEF（FBro SDK） | CDP 驱动独立 Chrome + 截图回传 |
| 检索 | Solr 127.0.0.1:8984 | SQLite FTS5（中文分词按字切） |
| 本地 API | WebSocket 9002 | HTTP REST + SSE |
| 打包 | 加壳单文件 exe，联网验签 | 源码运行，零依赖 Node |
| 更新 | 远程拉取并覆盖 exe | 不做（git pull 自行更新） |
